## doors94 UX notes

Ideas not yet built, roughly in order of payoff.

- **Playground history**: keep the last few comparisons in the window so a user can flip between prompts without re-running them.
- **Rule-level diff**: let the user toggle individual rules off in the Playground and re-compare, to see what each rule actually changes.
- **Share an agent**: export/import a manifest as JSON (or a URL fragment) so agents can be sent to a friend.
- **Agent Creator inline help**: a short "What makes a good rule?" example under the Rules step, reusing Read Me content.
- **Status/log panel**: surface storage and validation warnings that currently only go to the console.
- **Touch and small screens**: the desktop assumes a mouse and a wide viewport.
